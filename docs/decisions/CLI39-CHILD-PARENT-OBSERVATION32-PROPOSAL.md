# CLI32 child-side parent observation proposal

Status: source-only architecture proposal, not selected implementation or native admission.

The selected outer coordinator method requires each actual retained-caller/operation-host child to join its actual pipe peer to parent birth/principal observations. Current pipe worker supplies only a PID locator. Serialized parentLineage carries expected observations but cannot transport the parent's native originals. The parent retains its actual process/Job/child birth originals through the existing shared owner; no child collector replaces that owner.

Proposed fixed mechanism: pre-NPH construct one literal OpenProcess delegate (DWORD access, BOOL inheritance, DWORD PID to HANDLE) borrowed from the SAME resident kernel32 module using existing supervised fixed module/export/delegate preparation. Keep own13 unchanged. Only the actual completed source-owned pipe-peer PID may enter this collector, with expected parentLineage PID comparison as correspondence. Call OpenProcess once with PROCESS_QUERY_LIMITED_INFORMATION (0x1000), inheritance false. Retain raw HANDLE and native-return marker before GetLastError. NULL is failed acquisition; unknown return retains the whole original without retry. Do not request SeDebugPrivilege, elevation, provider changes or another process owner.

Use the actual returned parent query HANDLE for fixed GetProcessTimes and QueryFullProcessImageNameW (flags0), then existing held Advapi32 OpenProcessToken with TOKEN_QUERY8 and fixed TokenUser/TokenStatistics queries. Compare actual creation FILETIME, SID bytes, TokenId and AuthenticationId to the retained lineage observations. Image capacity derives exact admitted official-host path code units plus one rejection witness; truncated or unequal output cannot pass. Process exit FILETIME is raw only until actual exit is established. Separate token queries are observations, not an atomic principal snapshot.

The opened query process HANDLE and real query token HANDLE each receive independently eligible once-only CloseHandle phases. The process HANDLE is a query reference, never permission to terminate/resume/assign a Job. Native borrower quiescence plus actual terminal joins controls independent close; pin/free failures retain their own originals and overall closure failure without suppressing an unrelated eligible HANDLE close. Unknown entered native calls or Start/close outcomes remain retained. No blind retry or deadline widening.

Enroll a fixed child-parent book under SAME host/root/receiver/original deadline before arrays, emitter, Thread or native effects. Both child roles use this one source-selected collector; qualification-coordinator has no CLI pipe ingress and does not invoke it. Fixed preparation/worker/result/pin/SafeHandle/exception/close graphs and retained overlap charge the existing whole startup/operation reservation, with genuine amounts UNKNOWN. No guessed cap, generic handle/path/callback, parser-issued capability or new trust receipt is proposed.

Source call sequence if selected: host pre-NPH literal recipe initialization; native-root existing peer completion; fixed parent acquisition/query/close observation; local association constructor joins this original with actual lineage, expected official-host held source/image and existing parent native admission. Raw equal fields alone must not populate nativeAssociationOriginals or admittedInputOriginal. The external controlling owner and actual startup/profile/trust/loaded associations remain mandatory independent facts. No shared Core callsite change appears needed: the existing fixed parent-owned birth book remains authoritative and child query originals remain locally owned until actual host exit/closure. Core should assess this lifetime claim before implementation.

Microsoft declarations: [OpenProcess](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-openprocess) documents a returned query HANDLE, requested-access check and CloseHandle obligation. [GetProcessTimes](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-getprocesstimes) accepts limited query access and reports creation FILETIME; exit time requires actual exit. [QueryFullProcessImageNameW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-queryfullprocessimagenamew) accepts limited query access and reports success length excluding NUL. [OpenProcessToken](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-openprocesstoken) accepts a limited-query process HANDLE, returns a separately closeable token HANDLE and checks requested token access.

Local OpenProcess of observed peer PID must compare actual creation FILETIME/token/image to immutable lineage facts bound to actual controlling owner; parent exit/replacement before acquisition must fail that join. Lineage transport authentication remains separate, not established by matching serialized values. No shared callsite change selected for local observation alone. Recipe roster now four (export/delegate/acquire/process-close) plus six fixed birth-query workers = ten; own13 unchanged.
