## Phase authority and meanings

Events are INSTALL_PREPARE, ACTIVATE, LEASE_BIRTH, LEDGER_BIRTH, BORROW_OPEN, BORROW_CLOSE, ARCHIVE, NEXT_START_PREPARE, REVOKE_BEGIN, REVOKE_COMPLETE, QUARANTINE. N means exact nonzero digest of independently admitted existing original/range with full raw/native/source/rights/EOF joins. Z means all32 bytes zero AND independently demonstrated inapplicable/unborn at this frontier. H means latest committed existing snapshot range, or Z only if that class has never been born anywhere in this realm lineage. H does not mean nullable at caller discretion. Ledger snapshots, cumulative borrow history and terminal archives never reset to Z at a generation boundary.

Snapshots are original append-only ranges of reserved106..108, bound to the actual subject native objects and complete cumulative history. Their changing raw digests select a newly committed successor range, not a replaced physical snapshot file or fabricated original. Earlier snapshots remain retained and authenticated. No new physical original is smuggled into the128 table. An existing snapshot is N even when its represented active-borrow count is zero. A ledgerSlotSnapshotOriginal is Z before the actual ledger object has been born; nobody creates an empty ledger merely to fill a journal field. If an independently designated ledger already exists, its real complete snapshot is N at PREPARED, not an invented new empty ledger.
