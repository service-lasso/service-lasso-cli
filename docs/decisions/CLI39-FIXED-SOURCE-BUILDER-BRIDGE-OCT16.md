## Selected connection

Use one private Windows/Linux Node-API build-tool addon, compiled from this
repository's build-owner sources plus a small fixed adapter against the selected
original Node headers. The qualified build-plane Node process loads its exact
held addon bytes through a fixed absolute path. Product runtime/SEA/package code
never loads or publishes this addon. This introduces no public CLI action,
configuration/environment switch, generic spawn API or persistent issuer.

The adapter has one fixed build operation, not an executable/argv callback. Its
inputs are the complete original v3 build recipe bytes and fixed fresh staged
source/output occurrence; these are source constraints, not grants. It obtains
the genuine native build owner through CLI's private implementing constructor
inside the independently admitted build-plane launch. No JavaScript object,
JSON token, supplied boolean, external pointer or claimed manifest can create,
import or deserialize that owner. Current Core interfaces supply no constructor.
The full CLI constructor remains implementation debt. If no genuine original
exists, addon initialization/use must refuse without tool birth; a zero/default
instance, mocked factory or automatic current-user selection is forbidden.

## Fixed caller and schedule

Retain the source-owned Windows schedule already encoded in
scripts/build-source-runtime.mjs: Kernelbase and NTDLL import production; each
ordered complete CRT replacement compile/archive pair; actual full Node project
generation; actual generated config.gypi/used-flags read and complete selected
profile validation; full Node compilation; independent unchanged configuration
readback; actual runtime/output manifest joins. Native code derives all command
operands from this fixed recipe and retained originals. Caller bytes cannot add
commands, change order, renew the deadline or request another executable.

The addon owns this complete native schedule in one synchronous native entry on
the same actual issuing thread. It uses no N-API async worker, JS command callback
or per-command authority handoff. Its fixed native debugger/pipe loop drains both
streams while servicing bounded process/thread/image/exception/exit events.
Finite wait quanta and every polling/read/overflow/pending/error row belong to the
original profile and deadline; no unbounded poll, extra worker or implicit child
kill/detach is selected. Exact native configuration parsing must consume actual
held generated bytes; a caller-supplied validation boolean or arbitrary JS parser
callback cannot authorize compilation.

Before the first tool birth it joins the staged complete Node/overlay/native
source tree, all selected tools/scripts/libraries/headers/configuration/environment
objects, current loaded bridge/build-plane runtime and authentic source membership
to actual native held/loaded/principal/backing originals. Existing JS file hashes
and plan parsing do not provide this native owner or source authority. The
Windows prefix already captures real principal, held-file, root birth, child

## ABI, loading, cost and lifetime

Use only the Node-API C ABI selected by the retained original Node headers and
qualified build-plane runtime. The adapter must reject any incompatible actual
runtime/header/source tuple; no guessed ABI version or alternate installed Node
is selected here. Addon compiler/CRT/import dependencies and their complete
loaded source closure enter the build-plane tool inventory before loading.
Loading executes native code and requires its own actual held/loaded/source and
complete exact launch admission before that first native statement.

The native owner and its source/command/event/stream/token/file/process/thread/
image/attribute/readback buffers stay in a native rooted registry through actual
whole command and failure/retention closure. A JS return, garbage collection or
external-buffer finalizer cannot close a live original, free pending backing or
retire resource costs. Returned JS summary/manifest bytes describe held results;
they cannot reconstruct qualification or authority. Failure keeps all actual
prefix effects and the original first cause privately; no private path/argument/
source/error body is printed as a public diagnostic.

Full backing, native/kernel/cache/virtual/storage costs, module/stack/TLS and
N-API/runtime allocations must be charged in the separate actual build-plane
profile before effects. It borrows no product Service/Core/store allowance.
The original independently admitted initial ROOT/source/principal/reserve launch
is still a real input requirement, separate from implementing this constructor.
The source guard and terminal refusal remain until both OS routes and the full
conjunction are implemented, independently reviewed and freshly admitted.
